# Charmer — медиа-лендинг

Вёрстка лендинга по макету BASE (Фигма) и разбору анимаций из Loom
«Анимации в интерфейсе, сетка 6 на 4».

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start   # прод-сборка
```

## Как устроено

- **Скролл-хореография** — вся страница это одна sticky-сцена (`app/page.jsx`),
  фазы описаны сегментами в `lib/timeline.js` (имя + длина в экранах).
  Меняете длину сегмента — меняется темп соответствующей фазы.
- **Контент** — весь текст в `lib/content.js` (проекты, факты, принципы,
  умения, форматы работы, клиенты, отзывы, контакты).
- **Масштаб** — макет 1920; `1rem = 10px` при 1920 и растёт/уменьшается
  с шириной окна (2560 и 1440 скейлятся пропорционально, как в видео).
  Блоки-ячейки фиксированы по высоте 80px, «воздух» в середине сжимается
  при уменьшении высоты экрана.
- **Мобильная версия** (<900px) — статичный поток без скролл-анимаций.

## Что заложено из видео

- хиро 6×4 сверху и снизу: work-item (год, название, описание),
  fact-item в скобках (не интерактивны), логотип в `[ ]` слева сверху,
  стрелка вниз в `[ ]` справа снизу;
- ховер по проекту: всё размывается (blur 6px), в центре появляется
  картинка проекта (любая пропорция, высота ≤ 800px);
- по скроллу ячейки «шахматкой» хаотично исчезают, снизу приезжает блок
  принципов;
- принципы (1)(2)(3): слово и цифра меняются на месте, номер и текст
  переезжают лево → центр → право;
- «Что мы умеем»: заголовок фиксирован, пункты (1)–(6) подъезжают по
  скроллу, картинка слева меняется по активному пункту (можно видео);
- «Как мы работаем»: пункты (1)–(4) появляются последовательно;
- «Нам доверяют»: логотипы мотаются вверх, у логотипа в «скобках»
  появляется комментарий клиента (сейчас есть у Точки);
- контакты приезжают шторкой: красный фон, «Обсудим ваш проект»,
  кнопка `[→] charmer` (mailto), футер, «наверх».

## Что нужно доложить руками

1. **Шрифты** → `public/fonts/` (см. README там): Even Mono Regular и
   ABC Pelikan Condensed Medium (woff2). Пока их нет — системные фолбэки.
2. **Скобки-глифы**: сейчас нарисованы кодом (`Paren` в `app/page.jsx`);
   при желании замените path на экспорт SVG из Фигмы.
3. **Логотипы клиентов** → `public/brands/<id>.svg` и подключить вместо
   текстовых заглушек (`brandPh`).
4. **Картинки проектов и пунктов «умеем»** — сейчас градиентные
   заглушки (`hoverImage .ph`, `skillsImage .ph`).
5. **Тексты фактов** — заменить заглушки на тексты Веры
   (`lib/content.js → facts`).
